Features

Everything your server does, one click away.

NoCapOS runs as root on your machine, so it can manage the whole box — and every change is admin-only and written to an audit log.

App Store

One-click installs of Jellyfin, Nextcloud, Open WebUI + Ollama, Vaultwarden, Syncthing, Gitea, code-server, n8n and more — with updates, release notes and uninstall that keeps your data.

Files

Dual-pane file manager with previews, syntax highlighting, permission badges, a recycle bin and background copies with progress, conflict choices and cancel.

Root terminal

A real shell on the server — or inside any container — right in the browser, with a CRT mode and a clear badge when you're root.

Your Linux users

Sign in with the machine's own accounts, root included. Create users, set roles, reset passwords and turn on two-factor sign-in.

Network & power

Join Wi-Fi, switch between DHCP and static addresses with automatic rollback, restart or shut down — from a macOS-style Control Center.

Universal search

Ctrl+Space finds apps, settings, files and actions in one box, with a live file index and keyboard navigation.

Live monitoring

CPU per core, memory, disks, network and GPUs, plus container stats and logs — as widgets or full apps.

Remote Desktop & more

RDP to your PCs, a real Brave browser, one-click scripts, and an AI assistant that runs local models with Ollama.

Secure by default

argon2id passwords, rotating sessions, two-factor sign-in, a strict content-security policy, and protected system folders that Files can't delete.

Install

Up and running in two minutes.

Any 64-bit or ARM Linux machine with systemd: a mini PC, an old laptop, a NAS box or a Raspberry Pi 4/5.

01Run the installer

It picks the build for your CPU, checks its SHA-256 checksum, installs Docker if needed and starts the nocapos service.

curl -fsSL https://github.com/shatheitguy/nocapos/releases/latest/download/install.sh | sudo bash

02Open it and create your admin

The installer prints the address and a one-time setup token. Open https://your-server-ip/, accept the self-signed certificate once and enter the token.

==> NoCapOS is running.
   Open:  https://192.168.1.20/
   First-run setup token:  6962a448-…

03Options

OptionWhat it does
--storage /pathWhere NoCap Drive keeps your files (default /srv/nocapos)
--port 8443HTTPS port if 443 is taken
--no-dockerSkip Docker (the App Store stays off until it's installed)
--dockerRun NoCapOS itself in Docker — apps only, no control of the server
--uninstallRemove NoCapOS; your files are never deleted (--purge also removes accounts and settings)
