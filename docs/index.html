Your server, your screen, your phone. One OS.

NoCapOS is a full Linux operating system. Install it from a USB stick or SD card and you get a native NoCap Desktop on the screen, the same OS from any browser, ZFS storage, a firewall and ad blocker, virtual machines, an App Store and a phone app that keeps it all connected.

The OS

A real operating system, not just an app.

NoCapOS is built on Debian 13. Kernel and security updates come straight from Debian, and NoCapOS itself updates from Settings → Glow Up, along with the system packages, in one go.

NoCap Desktop on the screen

Plug in a monitor, keyboard and mouse and the machine boots into a full native NoCap Desktop session, branded end to end.

  • Native apps, windows and a dock on the physical screen
  • Repair and diagnostics built into Settings
  • Same experience on PCs and Raspberry Pi

The web OS from any browser

Open the server's address on a laptop, tablet or phone and get the whole OS: windows, Files, Settings, Terminal and every app.

  • Each person gets their own private space and look
  • Two-factor sign-in, sessions and an audit log
  • Can be kept local-only
Built in

Everything a home server needs, out of the box.

No add-ons to hunt for. Every change is admin-only, checked on the server and written to the audit log.

ZFS storage

Pools (mirror, RAIDZ1/2), snapshots with schedules, rollback and clones, encrypted folders, scrubs, disk health, cache drives and a mirrored boot drive. Erasing always asks you to type to confirm.

Shield

A firewall with presets, a "what's exposed" view and anti-lockout, plus a DNS ad and tracker blocker for your whole network with its own dashboard.

Virtual machines

Virtual Desk runs full virtual machines with a step-by-step wizard, live usage, snapshots and each machine's screen in its own window.

App Store

One-click self-hosted apps in Docker, with updates, release notes and per-person access. Edit containers, networks and Compose stacks when you want more control.

File sharing

Shared folders over Samba and WebDAV with Read & write, Read only or No access per person, guest shares, network drives and cloud folders.

Backups

Encrypted, scheduled backups to a drive, SFTP or S3-compatible storage, Rewind to bring back any file from any day, and export & restore of NoCapOS itself.

AI Agents

Let AI agents use your server over MCP, each with its own enforced permissions: which folders, which tools, from where and until when. Anything that changes something waits for your OK.

Two voices

Every screen speaks Gen Z by default, or switch to Standard for plain, classic wording. The phone app follows along.

Glow Up updates

NoCapOS and the system packages update together from Settings → Glow Up. Kernel and security fixes come from Debian.

Download

Install it your way.

Grab the newest build from GitHub Releases. Every download comes with a SHA-256 checksum.

PC installer (x86)

Write it to a USB stick and boot. It starts the NoCap Desktop with an Install NoCapOS app; a text-mode installer is there for servers without a screen.

nocapos-<version>-amd64.iso
Download ISO

Raspberry Pi image

Flash it to an SD card or SSD for a Raspberry Pi 4 or 5 (64-bit), boot, and open it from your browser or the screen.

nocapos-<version>-rpi-arm64.img.xz
Download Pi image

Already running Debian, Ubuntu or Raspberry Pi OS?

Install NoCapOS on top with one line. It picks the build for your CPU (amd64, arm64, armv7), checks its SHA-256 checksum and starts the nocapos service.

curl -fsSL https://github.com/shatheitguy/nocapos/releases/latest/download/install.sh | sudo bash

01Open it

Go to the address shown on the screen from any device on your network, or use the NoCap Desktop. From outside your network, setup also asks for a one-time token.

02Make it yours

Create your admin account, then pick a voice, theme, name, network, time zone and updates. Skip anything and change it later in Settings.

03Stay fresh

Updates come from Settings → Glow Up: NoCapOS and the system packages, in one go. Your accounts, settings and files stay put.

Installer options
OptionWhat it does
--storage /pathWhere NoCap Drive keeps your files (default /srv/nocapos)
--port 8443HTTPS port if 443 is taken
--no-dockerSkip Docker (the App Store stays off until it's installed)
--uninstallRemove NoCapOS; your files are never deleted (--purge also removes accounts and settings)

Your data stays yours. No cap.

NoCapOS and the NoCap OS phone app collect no data: no analytics, no tracking, no account with us. Your server talks to your devices directly. Crash reports are only sent if you choose to send them.
